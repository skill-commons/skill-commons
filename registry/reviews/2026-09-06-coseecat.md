## Decision and source identity

Admit `coseecat` **1.0.0** at `curated` maturity, scoped to public CoSEE-Cat DR1 event
summaries, published diagnostic PNGs, and descriptive catalogue analysis. CRS and
Skill Commons are the continuing source steward and registry authority.

- Repository: `https://github.com/skill-commons/curated-research-skills`
- Tracked default branch: `main`
- Merged commit: `684f4e5301123cc614082373dea304c1fdf43937`
- Directory: `skills/coseecat`
- Git tree: `3236a546c437d66022b3dc7597e3940b2cd3c123`

The complete assessed directory contains four files: `SKILL.md`, `LICENSE`,
`references/catalogue.md`, and `scripts/coseecat_demo.py`. All support files are
referenced from the entrypoint. The current Hermes submission contract staged this
exact tree without category, packaging, or selection warnings; the tree was resolved
again from the merged CRS commit. No skill bytes or archive products are copied into
this registry.

The skill provides reusable catalogue discovery, selection, interpretation and caching,
not separate skills for a fixed event or figure. Its maturity reflects explicit scope
curation, inspected code and sources, independent technical exercise, maintained
regressions, and continuing stewardship; it is not inferred from CRS membership.

## Evidence

- **Rights and attribution:** original instructions and helper carry the CRS MIT
  license and contributor attribution. The public DR1 metadata declares CC0 and asks
  users to cite Warmuth et al. (2025). Both source and generated reports preserve the
  paper and release references. The skill does not extend that declaration to externally
  hosted movies or distribute instrument data/plots as package assets.
- **Source/redaction inspection:** the complete skill was inspected. No embedded
  credentials, private GitLab content, home paths, private transcripts, or unfilled
  templates are included. The account-specific author guide informed the packaging
  and isolated-environment contract without being copied into the public skill.
- **Security and operational scope:** the helper permits public query/read requests
  only to fixed AIP TAP/DataLink endpoints and event-specific archive PNG paths. It
  checks event identity, table units/columns, duplicate IDs, DataLink semantics and
  descriptions, MIME types, PNG decoding/dimensions, TAP completion and the row cap.
  Responses are bounded at 8 MiB with connect/read timeouts. Redirects and ambient
  netrc/proxy configuration are disabled. Local outputs must be outside the installed
  skill; symlinks/unrelated contents are refused. Caches are checked by SHA256 and
  source/query identity before replay, with no silent refresh or broad cleanup.
- **Portable setup:** both pip and uv instructions carry identical direct pins:
  PyVO 1.9.1, requests 2.34.2, Astropy 8.0.1, NumPy 2.5.1, and Matplotlib 3.11.1.
  Fresh isolated macOS ARM64 CPython 3.12.4 uv environments succeeded in both the main
  and independent passes, with dependency checks passing. Existing path refusal and
  direct-import coverage are regression-tested. No shared Ori environment was modified.
- **Regression/CI:** all 374 CRS tests passed; one unrelated opt-in NIFTy integration
  was skipped. The helper has 67 regression cases plus shared portable-environment
  and discovery checks. Required CRS PR 14 `validate` CI passed, as did explicit helper
  Ruff lint/format checks. Live testing caught and corrected a MAXREC interoperability
  failure, buffered DataLink reader compatibility, and clipped figure headings before
  merge. Generic Codex validation rejects Hermes-required author/version fields; the
  authoritative CRS and current Hermes contract accept and require them.
- **Live event evidence:** events `2011171841` and `2011181438` each yielded one main
  catalogue row, seven DataLink rows, and five original published diagnostic PNGs. New
  timeline values were checked against the source timestamps; missing radio onset in
  the second event remained missing. The anchor's VDA offset is -16.1 min relative to
  EPD onset, with the published 0.9 min standard uncertainty and no extra light-time shift.
- **Catalogue arithmetic:** all 303 exported rows were checked against source VOTable
  values. Independent NumPy timestamp calculations verified each usable rise time.
  There are 300 usable pairs: impulsive 230 (median 7 min), gradual 57 (19 min),
  intermediate 5 (12 min), unknown composition 8 (5 min). Three missing peak times
  are explicitly excluded; three zero rises and the 1200-minute maximum are retained.
  Values are computed from the cached snapshot, not inserted as expected answers.
- **Independent forward test:** a separate agent followed the skill in a fresh
  workspace, independently parsed raw XML rather than calling the helper's analysis
  functions, and reproduced the event timing and all 303 comparison rows. It inspected
  all seven generated/retrieved figures and local HTML image references. It reported
  no blocking findings. This pass followed an earlier usage-limit interruption; the
  completed pass, not the interrupted attempt, is the evidence recorded here.
- **Reproducibility:** independent socket/DNS-blocked replay kept all 14 anchor-event
  and eight comparison-bundle files byte-identical, including retrieval timestamps.
  The main pass additionally exercised the missing-radio event under a socket/DNS
  audit hook, checked source modification times and all artifact hashes, and checked
  figure-title/axis/footer bounds. This establishes local replay of those snapshots,
  not a cross-platform or transitive-dependency reproducibility guarantee.
- **Registry checks:** all 41 registry tests, Ruff lint/format, generated-catalog and
  whitespace checks passed. Live upstream verification reported all 25 records as
  current, including this exact landed CoSEE-Cat source commit and tree.

## Boundaries and limitations

The workflow does not retrieve raw instrument arrays, reduce detector observations,
reconstruct a spectrum from pixels, perform real-time space-weather monitoring, or
download movies. Original published diagnostics are labelled separately from new
catalogue-summary figures. The EUI image is contextual and may precede the flare;
the inspected IP-context plot explicitly contains panels with no PAS data. Presence
of a DataLink plot is not evidence of a measurement in every panel.

TSA/VDA release times already include a Sun-to-Solar-Orbiter light-travel shift. VDA
bars represent a fit standard deviation, not all model/systematic uncertainty.
Observed onset, inferred release, main STIX peak and association-selected STIX peak
remain distinct. Estimated GOES class and direct GOES measurements remain distinct.
The ion-composition grouping is not defined from the rise times under comparison.

Catalogue metadata discrepancies and missing/unknown text states are documented,
including EUI `cor`, anisotropy `large`, confidence-scale differences, and `Y` flags.
Statistics are descriptive, with unknown groups and exclusions exposed; no causal
test or exposure-normalised event rate is claimed. Independent technical reproduction
does not independently validate the catalogue team's instrument processing or event
associations.

The live checks sample two event bundles and one 303-event comparison on one OS/Python
configuration. CI primarily checks deterministic contracts, not Linux instrument-data
execution. Direct package pins are not a transitive lock. The no-proxy helper needs a
separately reviewed access recipe on networks requiring an environment proxy.

Registry admission is not runtime permission or pod deployment. No live Ori installation,
vendored content, image pin or production image was changed. Clients must refresh the
registry and install the newly published skill through their normal runtime workflow.
