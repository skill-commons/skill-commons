# Git-first monorepo v0.5

This inert snapshot preserves the Commons-specific metadata schema, lock format,
validation profiles, converter, packer, threat model, and tests developed before the
federated-registry decision.

It is valuable design history, but it is not the current Skill Commons standard or
runtime. Files retain their original relative layout below this directory so the design
can be studied or revived deliberately. Default packaging, linting, tests, and catalog
generation exclude it.

The corresponding active copied-skill tree is preserved in Git at commit
`1671891c805c8d2644f0fe86a0c84579ba17a3a0`; the maintained curated successors are in
`skill-commons/curated-research-skills`.
