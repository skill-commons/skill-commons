# OCI Phase-0 evidence

This directory preserves the exercised OCI publication vertical slice. OCI is not
required for contributing, browsing, publishing, or installing current Skill Commons
packages.

The slice includes:

- the StarHorse 2.0.2 publication recipe and release evidence;
- deterministic preparation, catalog, signature, attestation, and verification code;
- the GitLab publication script;
- the former signed-catalog schema and regression tests.

The complete runnable pre-warehouse layout is available at commit `ac56d5a`. The
container repositories remain preserved in archived AIP GitLab projects.

Reactivation requires evidence meeting the OCI re-entry criteria in the current
[Git-first architecture](../../docs/SKILL_COMMONS_GIT_FIRST_ARCHITECTURE.md).
